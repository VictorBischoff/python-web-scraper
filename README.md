# Python Web Scraper

A Python web scraping project for automated data extraction.

## Project Structure

```
├── main.py           # Main script for web scraping
├── .env.example      # Example environment variables
├── pyproject.toml    # Project dependencies and configuration
├── .python-version   # Python version specification
└── .gitignore       # Git ignore rules
```

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/VictorBischoff/python-web-scraper.git
   cd python-web-scraper
   ```

2. Set up your environment:
   - Copy `.env.example` to `.env` and fill in your configuration
   - Install dependencies (requires Python as specified in `.python-version`)

## Usage

Run the main script:
```bash
python main.py
```
